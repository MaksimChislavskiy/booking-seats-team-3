# 🔧 Настройка окружения: локально и в Docker

Проект использует **один файл окружения `.env`**, который лежит в папке `infra/`.

Ключевой параметр в нём:

```bash
POSTGRES_HOST=db
```

Это имя сервиса PostgreSQL в Docker Compose.

Однако локальный backend должен подключаться не к `db`, а к `localhost`.
Именно поэтому в конфигурации приложения добавлена логика:

* если код **запущен внутри Docker**, переменная окружения `RUN_IN_DOCKER=yes` указывает использовать `POSTGRES_HOST` из `.env`
* если приложение **запускается локально**, автоматически подставляется `localhost`

Таким образом, один `.env` подходит для обеих сред.

---

## Локальный запуск backend

```bash
cd src
uvicorn app.main:app --reload
```

* Docker-контейнер с базой данных пробрасывает порт `5432` наружу.
* Локальный backend подключается по адресу:

```bash
localhost:5432
```

(`POSTGRES_HOST` игнорируется благодаря логике в конфиге.)

Alembic также использует этот режим.

---

## Запуск Docker-инфраструктуры

```bash
docker compose -f infra/docker-compose.yml up --build
```

* Внутри контейнера переменная `RUN_IN_DOCKER=yes`
* Приложение использует:

```bash
POSTGRES_HOST=db
```

Потому что внутри Docker все сервисы находятся в одной сети, и `db` — это hostname контейнера PostgreSQL.

# Шаблон для проектов со стилизатором Ruff

## Основное

1. Базовая версия Python - 3.11.
2. В файле `requirements_style.txt` находятся зависимости для стилистики.
3. В каталоге `src` находится базовая структура проекта
4. В файле `srd/requirements.txt` прописываются базовые зависимости.
5. В каталоге `infra` находятся настроечные файлы проекта. Здесь же размещать файлы для docker compose.

## Стилистика

Для стилизации кода используется пакеты `Ruff` и `Pre-commit`

Проверка стилистики кода осуществляется командой

```shell
ruff check
```

Если одновременно надо пофиксить то, что можно поиксить автоматически, то добавляем параметр `--fix`

```shell
ruff check --fix
```

Что бы стилистика автоматически проверялась и поправлялась при комитах надо добавить hook pre-commit к git

```shell
pre-commit install
```
